## Deskripsi

Sistem Penyewaan PlayBox merupakan aplikasi berbasis
Command Line Interface (CLI) yang dibuat menggunakan
bahasa pemrograman Java.

Aplikasi ini digunakan untuk mengelola data PlayBox,
pelanggan, transaksi penyewaan, pembayaran, dan
pengembalian PlayBox.

## Fitur

- Melihat data PlayBox
- Menambah pelanggan
- Melihat data pelanggan
- Menyewa PlayBox
- Mengembalikan PlayBox
- Melihat transaksi
- Melakukan pembayaran

## Class yang Digunakan

- PlayBox
- PS4
- PS5
- Pelanggan
- Transaksi
- Main

## Penerapan Inheritance

Class PlayBox digunakan sebagai superclass.

Class PS4 dan PS5 merupakan subclass dari PlayBox.

Inheritance diterapkan menggunakan keyword extends.

Contoh:

public class PS4 extends PlayBox

public class PS5 extends PlayBox
